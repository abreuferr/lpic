# LPIC-3 306-300: High Availability and Storage Clusters

Este diretório é a trilha atual de alta disponibilidade e armazenamento que
substitui parte do 304-200. A prática exige pelo menos duas VMs e uma rede de
laboratório isolada; comece pelos conceitos antes de instalar um cluster.
